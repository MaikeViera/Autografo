# Autógrafo

Sistema de gestão de fichas de assinatura e documentos para rotinas cartorárias.

**Status:** finalizado, conforme informado pelo autor.

## Sobre o projeto

Aplicação desktop que reúne cadastro e consulta de fichas, documentos anexos, histórico e protocolos. Inclui geração de documentos e uma aplicação web para consulta de fichas por QR Code.

## Funcionalidades

- Cadastro e consulta de fichas de assinatura.
- Gestão de documentos anexos e histórico.
- Controle de protocolos.
- Geração de documentos.
- Consulta de fichas por QR Code, com integração entre aplicação desktop e web.

## Tecnologias

C# · .NET · WPF · SQL Server · Python · Flask.

## Contexto

O projeto combina experiência prática em cartório com desenvolvimento de software voltado à organização de informações e documentos.

Este repositório apresenta o projeto. Código-fonte, instaladores e demonstração não estão incluídos nesta versão de apresentação.
